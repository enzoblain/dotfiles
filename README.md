# Dotfiles

My personal collection of dotfiles and configuration files for my development environment.

This repository is where I keep the setup and tweaks I use to make my tools feel the way I want them to. It evolves over time as I try new things, change workflows, or discover better ways of doing things.

The goal is not to build the most complete or universal setup, but simply to have a comfortable environment that works well for me.

## Setup

Most configurations can be used directly or symlinked into their expected location. Feel free to pick and choose whatever is useful rather than treating this repository as an all-or-nothing setup.

Some parts may be specific to my machine or workflow, so you might need to adjust a few things before using them elsewhere.

## Notes

These dotfiles are a work in progress. Things will change, break, get removed, and probably get rewritten at some point.

If you find something useful here, feel free to borrow it, modify it, and make it your own.
